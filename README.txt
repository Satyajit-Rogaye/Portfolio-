SATYAJIT ROGAYE — DATA ANALYST PORTFOLIO
========================================

FILES
- index.html: page structure and portfolio content
- style.css: responsive styling and layout
- script.js: theme toggle, mobile navigation, project filters/search, project details modal, certificate search/preview
- assets/resume.pdf: resume copy
- assets/certificates/: uploaded certificate documents

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in Chrome/Edge, or use VS Code Live Server.
3. Internet is only needed for Google Fonts; the main site and bundled certificates work locally.

PERSONAL PHOTO
Replace assets/profile-placeholder.svg with your own photo, or edit the image path in index.html.

GITHUB
Profile links are set to https://github.com/satyajit-rogaye.
Some repository links are based on repository names visible in the screenshots. Verify each exact URL in GitHub before publishing.
